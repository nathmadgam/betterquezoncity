# Better Quezon City

A community-run portal for **Quezon City, Metro Manila**: city officials, offices, services and public information in one place.

Better Quezon City is a volunteer project listed in the [BetterGov.ph LGU Directory](https://lgu.bettergov.ph/). It is **not** an official website of the Quezon City government.

## About Quezon City

Quezon City is a highly urbanized city in Metro Manila (National Capital Region) and the most populous city in the Philippines, with 142 barangays in six legislative districts. It is nicknamed the City of Stars because major broadcasting networks and much of the entertainment industry are based there.

Sources: [Quezon City Government](https://quezoncity.gov.ph/).

## Run it locally

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

Site content lives in `content/` (Markdown and YAML) and `src/data/`. See [CONTENT-MANAGEMENT.md](CONTENT-MANAGEMENT.md) for how to edit pages without touching code.

## Contributing

Many service pages are still placeholders. If you know how a service works in Quezon City (requirements, office, fees, schedule), open an issue or a pull request. Please cite a public source for facts about officials, offices and fees.
